FAQ

Questions developers ask

Direct answers on weights, licensing and local use. If you need more detail, write to us.

What do I need to run it locally?

One GGUF file of about 16GB, and a library that reads GGUF such as llama.cpp or llama-cpp-python. Run it with enough RAM or VRAM to hold the weights as they are.

Can it run on a machine with less memory?

The published file is F16. To use less memory, quantise it yourself with llama.cpp tooling before running. Quantising shrinks the file and may affect output quality.

What are the terms of use?

The weights are published under the LLaMA Community licence. Commercial use is allowed within that licence's terms, so read it on the model card before relying on the model in a product.

How do I report a bug or suggest an improvement?

Send the details to egytronic.official@googlemail.com with the steps that led to the problem and we'll get back to you.
